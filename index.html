クロール プライバシーポリシー

最終更新日：2026年5月

「クロール」（以下、「本アプリ」）は、ユーザーのプライバシーを尊重し、 個人情報の適切な保護に努めます。

1. 収集する情報

  • アカウント情報
  • プロフィール情報
  • 投稿画像
  • 位置情報
  • フォロー・いいね情報
  • 通知トークン

2. 利用目的

  • 地図上での投稿表示
  • SNS機能の提供
  • サービス改善
  • 安全性向上
  • 通知配信

3. 位置情報について

本アプリでは位置情報を利用します。 一部投稿は市区町村単位などへ曖昧化して表示される場合があります。

4. 通知について

いいね通知、フォロー申請通知、フォロワー投稿通知などを送信する場合があります。

5. 外部サービス

  • Firebase Authentication
  • Cloud Firestore
  • Firebase Storage
  • Firebase Cloud Messaging

6. 投稿データの削除

投稿はユーザー自身で削除できます。 一定期間経過後に自動削除される場合があります。

7. 通報・ブロック機能

本アプリでは安全性維持のため、通報機能およびブロック機能を提供しています。

8. お問い合わせ

本ポリシーに関するお問い合わせは、運営者までご連絡ください。
